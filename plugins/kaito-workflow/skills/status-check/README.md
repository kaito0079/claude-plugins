# status-check

作業を再開するときや、別のセッションで同じリポジトリを触った後に、今どうなっているかを決まった手順で確認するスキル。

## 使い方

```
/status-check
```

「状況確認して」「今どうなってる？」と頼んだときにも自動で使われる。

## 確認すること

1. ブランチ、未コミットの変更、未 push のコミット、upstream との差、stash、worktree
2. PR と CI の状態 (`gh` が使える場合)
3. 未 push のコミットそれぞれが、このセッションの作業と関係があるか (別のセッションのコミットが混ざっていないか)

## 報告の形

「現在地」「このセッションで決めたこと」「未決事項」「次の一手」の 4 つの見出しで、それぞれ 3 行以内にまとめる。

## しないこと

ファイルの編集・コミット・push・ブランチの切り替えはしない。関係のないコミットを見つけても、取り消さずに報告だけする。
